EP01~EP04에는 분리된 Teaching Point/Interaction 원본 필드가 없고 기존 hint를 사용하는 설계다. 이들을 임의로 누락으로 판정하거나 새 문장을 생성하지 않았다.

- 서재의 실제 카드 링크로 각 책을 열고, 전체 60장면을 각 화면 크기에서 끝까지 이동했다. 이전/다음과 첫·마지막 버튼 상태, 마지막 쪽수, 서재 복귀를 확인했다.
- 화면 본문은 표시용 줄바꿈만 제외하면 원본과 문자·순서가 일치했다. 펼친 부모 안내의 모든 문단을 원본 필드와 대조했다. 장면 이동 시 닫힘을 확인했다.
- 실제 이미지 URL·로딩·자연 비율과 장면 번호를 확인하고, 60장면 전체의 이미지/본문을 도서별 모아보기로 육안 대조했다. 명확한 파일 누락·번호 뒤바뀜은 발견하지 않았다. 생성 이미지의 모든 세부 묘사에 대한 정밀 편집 승인을 뜻하지 않는다.
- EP05는 이미 존재하는 등록 보관본의 12개 Text/Teaching Point/Interaction과 출판 JSON이 일치함을 확인했다. 원본 이미지 12개도 보관 입력과 출판 파일의 바이트가 일치했다. 읽기 전용 비교이며 재등록하지 않았다.
- 카드 제목·표지·연령·category 태그를 출판 데이터와 대조했고, 짧은 theme/summary는 PR #30의 서재 전용 문구와 일치했다. 이 문구와 원래 theme의 차이는 의도된 표시 설정이다. 다른 책이 열리는 연결 오류는 없었다.
- 서재는 5권, 빌드 HTML은 서재와 도서 5개로 총 6개였다. 공개 정적 자산에는 등록 장면 이미지와 파비콘만 있었다. 테스트·미완성 도서의 의도치 않은 노출은 발견하지 않았다. `/book/test-book/`, `/book/ep06/`, 입력 원고와 보관 원고 URL은 404였다. 놀이 속 `〇〇`/`OO`는 아이 이름을 넣는 의도된 대화 예시다.

## 브라우저·검사 결과

Chromium 실제 브라우저, 로컬 빌드 결과:

- 휴대폰 390×844, 태블릿 768×1024, 데스크톱 1440×900.
- 5권×12장면×3크기 = **180회 장면 확인**, 에세이/놀이 5권×2패널×3크기 = **30회 자료 패널 확인**.
- 기존 등록 본문 중 가장 긴 피코 12쪽(132자)을 포함해 긴 본문과 펼친 부모 안내를 확인했다. 세 크기에서 root 글자 크기를 200%로 확대해 동화·에세이·놀이와 부모 안내의 세로 읽기/가로 넘침을 확인했다.
- 이미지 로딩 실패는 360×800에서 EP05 1쪽 이미지 요청을 의도적으로 차단해 재현했다. 기존 안내가 표시되고 본문/부모 안내는 읽을 수 있었으며, 다음 장면은 실제 이미지가 다시 로드됐다. 실제 등록 이미지를 삭제하거나 교체하지 않았다.
- 대사·속마음: 피코 1쪽/EP05 2쪽의 대사, 림보 6쪽의 속마음 확인. 피코 10쪽의 `'이겨야만 해'라는`, EP05 5쪽의 `'비밀의 망토'란다`, 이름과 몽의 `'뚝!'`는 잘못 분리되지 않았다. 애매한 중첩 인용은 기존 표시를 유지한다.
- 탭 전환 후 제목 위치, 키보드 동작·접기/펼치기·포커스, 서재 복귀를 확인했다. 가로 넘침과 JavaScript 예외는 없었다. 모바일/데스크톱 장면·자료 캡처를 육안 확인했다.
- 카드 세부 정보는 5권×3크기 = 15회 별도 대조했다.
- `npm test`: 105개 통과, 선택형 신규 등록 통합 테스트 1개 제외.
- `npm run content:check`: 출판 파일·이미지·도서/에세이 연결 통과.
- `npm run check`: 오류·경고·힌트 0.
- `npm run build`, `git diff --check`: 통과.

## 확인하지 못한 항목 / 제외 범위

- 실제 iPhone/iPad/Android 기기, Safari·Firefox·Edge 및 스크린리더 음성 안내, 실제 터치 조작. 휴대폰/태블릿은 Chromium의 화면 크기로 대표했다.
- 브라우저의 기본 줌·운영체제 글꼴 확대 전체 조합. 200% 확인은 root 글자 크기 확대 방식이다.
- 배포 URL·실제 가족 네트워크·느린 모바일 회선·오프라인 상황·외부 참고 링크의 현재 접속 가능 여부. 로컬 이미지 요청 실패만 별도 재현했다.
- 철학 원전 인용·한국어 번역본의 정확한 문구/쪽수·뇌과학 효과와 실험 조건의 외부 사실 검증, 실제 가족 사용성 관찰.
- **신규 책 등록 실사용 테스트**는 요청대로 제외했다. `book:import`/draft 등록 명령을 실행하거나 실사용 출판 파일을 생성하지 않았다. 단위 테스트의 임시 합성 입력은 기존 검사 범위이며 파일럿 도서로 노출되지 않는다.
- 병합·자동 병합·Vercel Preview 생성·배포를 하지 않았다. 기존 `git.deploymentEnabled=false`를 유지한다.
