# Philo-book Illustrator Skill 변경 이력

## 1.0.1 — 최초 GitHub 등록

사용자가 제공한 `Philo-book_Illustrator_SKILL_v1.0.1.md` 전체를 수정 없이 등록했다. 원본의 `Updated: 2026-11-04`를 유지하며 GitHub 등록만으로 버전을 올리지 않는다.

- 그림책 일러스트레이션의 장면별 순차 생성 및 검수 지침을 등록했다.
- Character Bible·Common Art Style을 통한 캐릭터·화풍 일관성 관리를 포함한다.
- 이미지별 오류 검수와 문제 장면만의 부분 수정, 정상 이미지 보존을 포함한다.
- 기본 4:3 full-bleed 직사각형 캔버스와 직각 모서리 규격을 포함한다.
- 원본 v1.0.1 변경 요약에 따라 둥근 테두리·검은 외부 여백·장식 표시 문제의 검수와 부분 편집 기준을 기록한다.

v1.0.0의 원본과 실제 변경 날짜는 제공되지 않았으므로 별도의 과거 이력은 추정하지 않는다.

## 버전 관리 규칙

Author Skill과 독립적으로 Semantic Versioning을 사용한다.

- MAJOR: 기존 사용 방식과 호환되지 않는 변경
- MINOR: 새로운 명령이나 기능 추가
- PATCH: 품질 개선, 검증 강화, 문구 수정

실제 지침이 변경된 경우에만 버전 갱신을 검토한다. 실제 동작·출력 규칙이 바뀌면 SKILL.md의 버전과 이 변경 이력을 함께 갱신한다. GitHub 등록만을 이유로 버전을 올리지 않는다.
