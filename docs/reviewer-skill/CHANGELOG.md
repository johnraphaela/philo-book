# Philo-book Reviewer Skill 변경 이력

## 1.0.3 — 2026-11-07

- 중복 체크리스트, 응답 예시 및 Author 요청문을 통합했다. 네 모드, 판정·보고 형식과 최종 등록 검수를 보존했다.

## 1.0.2 — 2026-11-07

- 최종 파일에서 라벨과 필드 경계를 확인하고 누락된 실제 출처를 Author에 전달한다. Author 출력 규격 위반과 실제 파싱 차단은 구분한다.

## 1.0.1 — 2026-11-04

- Author용 `/revise` 요청문을 두 단계 출력으로 명확히 했다: 장면·항목별 변경 내용과 이유를 먼저 보여주고, 수정하지 않은 내용까지 포함한 전체 Codex 전달 원고를 Markdown 코드 블록 하나로 이어서 출력한다.
- Metadata·기본 12장면·장면별 부모 콘텐츠·에세이·Harvard Play·캐릭터/화풍·장면별 프롬프트·References와 연속성 검사를 포함한다. 확정된 다른 장면 수·실제 파일 형식은 보존한다.
- 사용자 요청 범위에 추가 승인 단계를 두지 않고, 최종 원고에는 검수 의견·수정 이력·대체 참조 문구를 넣지 않는다. 전체 원문이 없으면 추측한 최종본을 만들지 않는다.
- Reviewer의 진단 역할과 기존 네 명령·판정·검수 결과 구조를 유지한다. 이번 명시적 코드 블록 출력 요청은 Author에게 전달하며 기존 Author·Illustrator 지침과 출판 콘텐츠는 수정하지 않는다.

## 1.0.0 — 최초 GitHub 등록

사용자 제공 `Philo-book_Reviewer_SKILL_v1.0.0.md`를 첫 버전의 기준으로 등록했다. 원본의 Updated 날짜 2026-11-04와 버전 1.0.0을 유지하며 미확인 과거 이력·테스트 결과는 추정하지 않는다.

- 독립적인 어린이 철학 그림책 원고 검수와 8개 영역의 품질 기준을 보존했다.
- PASS / REVISE / BLOCK, 최소 수정 범위의 Author `/revise` 프롬프트 생성, 수정본 `/recheck`, 최종 Markdown `/check-export` 지침을 포함한다.
- Gemini·ChatGPT 공용 텍스트 명령과 수동 적용·실행 환경 한계를 명확히 했다. 특정 모델의 도구·자동 설치를 가정하지 않는다.
- Markdown 행 끝 공백을 정리했다. 원본을 바탕으로 6개 결과 항목과 재검수 대상 표시를 명시하고, 주관적 편집 제안을 BLOCK으로 분류하지 않도록 판정 문구를 명확히 했다.
- 실제 등록 규격에 맞춰 연령 0~18 및 최소 ≤ 최대, 선택 필드 생략, 질문 구문·중복, 에세이 하위 필드·참고문헌·선택 English, Author의 단일 UTF-8 Markdown 전달 규칙을 보완했다. 기존 Author·Illustrator나 사이트 규격을 바꾸지 않는다.

## 버전 관리

Author·Illustrator와 독립적으로 Semantic Versioning을 사용한다. 비호환 사용·판정 계약 변경은 MAJOR, 호환 가능한 명령·기능 추가는 MINOR, 품질·검증·문구 개선은 PATCH로 검토한다. 향후 Reviewer 지침을 변경할 때 버전·실제 변경일·이 변경 이력을 함께 갱신한다. 이번 첫 등록의 명확화는 1.0.0에 통합하며 등록만을 이유로 버전을 올리지 않는다.
