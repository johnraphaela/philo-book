# 서재 필터 점검과 변경안

기준: PR #31까지 병합된 main의 등록 도서 5권. 원고·출판 JSON·에세이·놀이 내용은 수정하지 않는다.

## 실제 메타데이터 대조

| 도서 | ageGroups 원문 | recommendedAge | categories 원문 | theme 원문 |
| --- | --- | --- | --- | --- |
| EP01 로봇 몽의 가슴 부품 | `5-7세`, `초등 저학년` | 5~9 | 자아, 변화, 테세우스의 배 | 정체성과 연속성 |
| EP02 꼬마 등대 루미의 반짝이는 불빛 | `6-8세`, `9-11세` | 6~11 | 철학, 자존감, 자기만족, 코나투스 | 스피노자의 자기만족과 진짜 자긍심 |
| EP03 유리병 속 무지개와 파랑새 림보 | `5-7세` | 없음 | 철학, 정서발달, 자기효능감 | 희망과 능동적 실천 |
| EP04 은빛 깃털의 피코 (`pico-silver-feather`) | `5-10세` | 5~10 | 철학, 문학, 자아존중감 | 경쟁심 극복과 고유성(코나투스)의 발견 |
| EP05 비밀의 망토와 숲속 놀이터 (`ep05`) | `5\~8세` | 없음 | 사회 철학, 윤리, 사회성 발달 | 공정함, 배려, 롤스의 '무지의 베일' |

PR #30의 짧은 카드 theme/summary와 위 원본 theme는 유지한다. theme는 소개/검색용이며 주제 필터의 분류 근거로 사용하지 않는다.

## 발견된 누락

- 기존 연령 목록은 5~7 / 8~9 / 10~12세였고 `recommendedAge`만 검사했다. 해당 필드가 없는 EP03과 EP05는 모든 개별 연령 필터에서 누락됐다. 특히 `5\~8세`처럼 Markdown 이스케이프가 남은 숫자 범위를 읽지 못했다.
- 기존 주제 목록은 자아와 정체성 / 변화와 성장 / 자존감과 감정이며 `categories`가 아닌 `topics`를 검사했다. EP03·EP04·EP05는 topics가 없어 모든 개별 주제 필터에서 누락됐다.
- EP02의 legacy topics에는 identity도 있으나 categories에는 자아/정체성이 없다. 반대로 EP04의 theme에는 코나투스가 있으나 categories에는 코나투스가 없다. 이 두 값을 근거로 분류하면 사용자가 선택한 category와 무관한 책이 섞인다.
- `자존감`과 `자아존중감`은 표기가 달라도 같은 필터에서 찾을 필요가 있다. `사회 철학/사회철학`, `정서발달/정서 발달`, `사회성발달/사회성 발달` 등 띄어쓰기 차이도 정규화가 필요하다.

## 적용한 분류 변경안

1. 추천 연령을 5~6 / 7~8 / 9~10 / 11~12세로 나누고 경계 포함 범위 겹침으로 판단한다. 5~8세는 5~6·7~8 모두에 포함된다. 6세 추천 책도 5~6세 구간에 포함되므로, 구간 선택은 구간 전체가 아니라 일부가 겹친다는 의미다.
2. 명시적 `recommendedAge`가 있으면 이를 우선한다. 없을 때만 `ageGroups`의 숫자 범위를 읽는다. 하이픈·물결표·대시와 `\~`, 단일 나이·전각 숫자를 지원하고 여러 구간은 각각 유지한다. 예를 들어 5~6세와 9~10세를 5~10세로 합쳐 중간 나이를 채우지 않는다. 숫자로 판단할 수 없는 `초등 저학년`은 임의로 나이를 부여하지 않는다. 현재 EP01은 명시적 5~9세가 있어 누락되지 않는다.
3. 주제 3개를 실제 categories에서 만든 **13개 선택지**로 바꾼다. 새 category도 자동으로 목록에 나타난다. 원본 category는 수정하지 않고 알려진 동의 표기만 필터에서 정규화한다.
4. 하나의 책에 categories가 여러 개면 하나라도 일치할 때 포함(OR). 검색어·연령·주제 조건 사이에는 AND를 적용한다. 빈 선택은 해당 조건만 해제한다.
5. 철학과 사회철학, 자존감과 자기효능감, 자아와 코나투스를 같은 분류로 억지로 합치지 않는다. 선택한 category에 정확히 연결된 책만 포함한다. 검색어는 제목·소개·원래 theme·원래/정규화 category에서 계속 찾는다. legacy topics는 원본 스키마 호환용으로 보존하지만 화면 필터/검색의 근거에서는 제외한다.

기존 세 가지 큰 주제로 표현하기 어려운 실제 도서는 **림보(정서 발달·자기효능감), 피코(문학·자존감), EP05(사회철학·윤리·사회성 발달)**다. 본 변경안은 이들을 기존 주제로 추정 배정하는 대신 아래 실제 category를 노출한다. 별도의 상위 분류 체계나 희망·공정함 같은 새 내용 분류를 출판 데이터에 추가하지 않는다. 필요하다면 후속 편집 검토에서 결정한다.

## 검증 방법

`tests/library.test.ts`에서 현재 출판 JSON을 읽어 연령 4개·주제 13개·교차 조건 52개의 기대 도서 목록을 대조한다. 경계 겹침, 동의 표기, 미정의 category, 연령 구간 사이의 빈 범위, 숫자가 없는 연령, theme/topics를 통한 잘못된 분류 방지도 별도로 검사한다. 실제 서재 화면에서는 “모든” 선택까지 포함한 5×14=70개 조합의 카드 표시·권수·빈 결과·초기화를 확인한다.

검증 결과: `npm test` 103개 통과·선택형 등록 통합 테스트 1개 제외, `npm run check` 오류/경고 0, `npm run build` 및 `git diff --check` 통과. 스냅샷 테스트를 현재 5권으로 한정해 향후 신규 도서 등록만으로 기존 결과 표가 실패하지 않도록 보완한 뒤 필터 테스트 8개를 다시 통과했다. 모든 등록 category의 자동 선택지 반영은 전체 등록 도서를 대상으로 확인한다.

Chromium에서 360×800, 390×844, 430×932, 768×1024, 1440×900의 각 70조합(총 350조합)을 검증했다. 도서 ID 목록·권수·빈 결과·동의 표기 검색·원래 theme 검색·category만을 통한 분류·조건 AND·초기화와 검색 포커스·가로 넘침을 확인했고 콘솔 예외가 없었다. 모바일·데스크톱 캡처도 확인했다. 실제 기기·Safari·스크린리더 음성 안내는 별도로 검증하지 않았다.
