# Gemini Skill 변경 이력

## 1.0.3 — 2026-11-07

- 제작·승인·등록 지침의 반복과 사이트 구현 설명을 줄였다. 명령, 최종 Markdown 규격, 분류 ID와 실제 참고문헌 검증을 보존했다.

## 1.0.2 — 2026-11-07

- 중간 제작용 제목과 등록용 영문 라벨을 구분하고 Dialogue Questions, 에세이 Body, 실제 References의 위치와 필수 조건을 명확히 했다.
- 복사용 출력에도 동일한 형식 검증을 적용한다. 누락된 출처나 승인 문제를 해소할 수 없으면 최종 등록용 원고를 보류한다.

## 1.0.1 — 2026-11-04

- 기존 품질 개선과 추가 요구사항을 한 패치로 통합했다. Metadata 필수/선택 필드, 분류·세부 주제 소속, 연령·질문, 줄바꿈·연속 Scene 및 프롬프트 수의 최종 검증을 명확히 했다.
- `/export`는 승인된 전체 원고를 UTF-8 `Book ID.md` 파일 하나로 생성하여 첨부·다운로드 제공하는 것을 우선한다. 실제 존재·비어 있지 않음·첫 줄 Metadata·필드/섹션/장면 구분·원문 보존을 검사하고 성공 시 채팅에는 파일명과 완료 안내만 표시한다.
- 파일 생성 불가 또는 생성·검증·전달 실패 시 사실을 알리고 전체 원고를 복사 가능한 Markdown 코드 블록 하나로 대체한다. 가짜 다운로드 링크와 JSON·ZIP·Manifest·Review Report 추가 생성을 금지한다.
- 명령 및 자연어 새 그림책 요청에서 연령이 없으면 제작 전에 한 번 확인한다. 이미 지정한 연령은 재질문하지 않으며 추천과 선택 위임을 구분하고 위임 시 추천 연령으로 바로 진행한다.
- 3~5세, 5~7세, 7~9세, 9~12세의 표현·갈등·질문 기준을 추가했다. 개인차와 사용자 지정 연령을 우선한다.
- 감정 수용·주인공의 능동성·설득력 있는 열린 결말, 정답을 유도하지 않는 장면별 부모 콘텐츠, 원전 확인 범위와 이미지 프롬프트의 독립성·연속성 기준을 강화했다.
- 기존 3단계 승인·`--all` 일괄 제작·`/revise` 부분 수정 및 단일 Markdown 원칙을 유지한다. 연령 확인은 승인 단계에 추가하지 않는다. 한 권당 대상 연령대 하나·최종 원고 하나를 유지하고 연령 변경으로 영향받은 내용만 재승인한다.
- EP04 샘플과 출판 원고·이미지·승인 기록은 변경하지 않는다. 정적 검사를 실제 Gemini 품질 검증으로 표현하지 않으며 Gemini 수동 적용 원칙을 유지한다.

## 1.0.0 — 2026-11-04

- 제공된 Phase 4-A 개정 제작 지침과 EP04 샘플을 최초 GitHub 기준으로 등록했다. 이전 버전·승인 이력은 추정하지 않았다.
- 기존 연령·3단계 승인·전체 제작·장면별 부모 콘텐츠·에세이·활동·그림 프롬프트·단일 Markdown export 규칙을 유지했다.
- 등록기의 선택 Metadata 6개, 파이프/목록 질문, 카테고리·세부 주제 그룹과 질문 중복 검사, 180자 핵심 질문 상한을 명확히 했다.
- taxonomy.ts의 허용 ID 스냅샷과 코드·Skill·샘플의 동시 호환성 검토 원칙을 추가했다.
- 표준 샘플의 동화·에세이·장면별 부모 콘텐츠·12개 이미지 프롬프트를 보존하고 과거 편집 메모만 미승인 예시 안내로 정리했다.
- main 병합 후 사용자가 SKILL.md와 references/ep04-example.md를 수동 반영한다. 자동 동기화나 Gemini 배포는 하지 않는다.
