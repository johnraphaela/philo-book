# 캐릭터와 장면 일관성

캐릭터 설정은 `extensions.philoBookAuthor.characters`에 보관한다. 이 영역도 승인받은 설정만 확정값으로 취급한다.

권장 항목:

```json
{
  "id": "seed",
  "name": "씨앗",
  "fixedTraits": ["작은 타원형 갈색 몸", "잎 모양의 작은 초록 모자"],
  "allowedVariations": ["표정", "자세"],
  "style": "따뜻한 수채화 그림책",
  "constraints": ["장면마다 몸 색과 모자 모양 유지"]
}
```

이는 형식 예시일 뿐 실제 책의 승인된 캐릭터가 아니다.

1. 대상 장면과 등장 캐릭터 ID를 확인한다. 기존 설정이 없거나 모순되면 후보를 제안하고 승인을 기다린다.
2. 선택 장면의 `images[].extensions.characterIds`에 등장 캐릭터 ID를 기록할 수 있다. 루트 schema 밖에 새 필드를 만들지 않는다.
3. 프롬프트는 승인된 캐릭터 불변 특징→공통 화풍→원문 장면 행동·감정→구도·빛→금지 요소 순서로 작성한다.
4. 여러 장면에서 동일한 불변 특징 문구를 재사용한다. 장면별 변경은 표정·자세·배경 등 허용된 차이로 제한한다.
5. 원문에 없는 주요 사건·소품·인물·외형 변경은 제안과 승인 없이 확정하지 않는다. 필요한 시각적 보완은 후보로 표시한다.
6. 생성할 이미지는 실제 자산이 아니다. 파일명·assetPath·이미지 생성 완료·특정 도구의 seed가 있다고 꾸미지 않는다. 외부 이미지 생성 API를 호출하지 않는다.
7. 캐릭터 설정 변경이 다른 프롬프트에 미치는 영향은 보고만 한다. 선택하지 않은 장면 프롬프트를 자동으로 다시 쓰지 않는다.
