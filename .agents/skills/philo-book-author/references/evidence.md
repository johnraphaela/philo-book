# 철학과 실증 근거

## 세 범주를 구분한다

1. **철학적 해석**: 특정 개념과 이야기의 연결은 가능한 해석임을 밝힌다. 철학자의 직접 주장이나 정답으로 단정하지 않는다.
2. **실증적 근거**: 발달·교육·신경과학 효과는 확인한 연구나 공식 자료가 뒷받침하는 범위에서만 설명한다. 근거의 대상 연령·조건과 한계를 유지한다.
3. **창작 제안**: 동화 장면·놀이·대화 예시는 창작이다. 특정 기관의 공식 프로그램·추천·보증으로 표시하지 않는다.

`extensions.philoBookAuthor.evidence` 아래 `essay`와 `play`를 독립적으로 관리한다. 예시 구조는 `{ interpretationNotes: [], verifiedSources: [], pendingSources: [], limitations: [] }`이며 미사용 항목은 생략 가능하다.

## 인용과 참고문헌

- 직접 인용은 원문을 실제로 열어 정확한 문구와 위치를 확인했거나 사용자가 원문을 제공한 경우에만 사용한다. 사용자 제공 자료는 제공된 자료라는 점을 밝히고 독립 확인 여부를 구분한다.
- 출처를 확인할 수 없으면 인용부호·저자명·연도·페이지·DOI·URL을 만들어 넣지 않는다. 기억에 의존한 가짜 정확성을 피한다.
- 간접 설명은 직접 인용처럼 꾸미지 말고 해석·요약으로 표시한다.
- `verifiedSources`에는 실제 확인한 제목·저자/기관·URL/판본·확인 범위를 기록한다. URL을 확인한 적이 없으면 확인했다고 쓰지 않는다.
- 확인하지 못한 자료는 `pendingSources`와 누락값에 기록하며 essay.body나 activity.references의 확정 참고문헌에 넣지 않는다.
- 외부 자료를 읽는 도구가 없거나 접근이 거부되면 그 제한을 보고하고, 검증되지 않은 효과·인용은 제외한 검토용 초안으로 멈춘다. 자료 확보를 이유로 다른 콘텐츠 영역을 수정하지 않는다.
- 기존 승인 원고에 미확인 인용이 있으면 그대로 보존하고 문제를 알린다. 사용자가 해당 부분 수정도 요청한 경우에만 후보 수정안을 제시한다.

## 하버드 관련 표현

- 'Serve and Return', 실행 기능 등 개념과 창작 놀이 자체의 검증 여부를 분리한다.
- 기관명만으로 놀이 효과를 입증하지 않는다. 확인 없이 '시냅스가 폭발적으로 연결', '전두엽 발달 보장', '하버드 인증' 같은 표현을 새로 작성하지 않는다.
- 기존 표현의 교정은 revise로 해당 범위를 요청받았을 때 수행한다. Skill 호출만으로 기존 출판 콘텐츠를 바꾸지 않는다.
