# plan — 2~3개 방향의 기획

공통 규칙은 common-guide.md를 따른다. 후보의 `metadata` 중 요청 범위와 `extensions.philoBookAuthor.plan`만 작성한다. story·essay·thinking·images는 생성하지 않는다.

입력: 주제, 연령, 질문, Research Brief/참고문헌, 등장인물·배경, 희망 장면 수, 교육 목표, 문체·분위기. 주제와 연령이 없으면 질문한다. Research Brief가 없어도 사용자가 제공한 입력만으로 기획할 수 있으나 문헌 검증 완료로 표시하지 않는다.

서로 다른 철학적 접근의 기획안 2~3개를 제안한다. 사용자가 대안 수를 지정하면 그 범위를 따른다. 각 기획안에는 다음을 포함한다.

1. 핵심 철학 문제와 메시지
2. 참고문헌과 연결된 주장/창작적 해석의 구분 및 source ID
3. 인물의 성격과 배경
4. 중심 갈등과 선택
5. 사건의 흐름
6. 열린 결말의 방향
7. `sceneOutline: [{ sceneId, purpose }]`
8. 부모와 아이가 생각할 질문

선택 전에는 대안을 extensions에 보관하고 하나를 임의로 확정하지 않는다. 여러 대안이 같은 캐릭터·장면 ID를 공유한다면 선택 후의 일관성을 확인한다. 기존 장면이 있으면 해당 ID를 우선 재사용한다.

교훈을 대사로 설명하기보다 아이의 경험·감정·선택에서 질문이 드러나게 한다. 12장면은 별도 지정이 없을 때 제안할 수 있을 뿐 고정값이 아니다. 기획 선택·승인을 받은 뒤에만 정본에 반영하며, story 실행은 별도 요청을 기다린다.
