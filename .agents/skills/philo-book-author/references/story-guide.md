# story — 장면 원고

승인된 기획을 입력으로 받는다. 외부에서 제공·승인한 기획도 허용한다. 저장소에 기획이 없다는 이유로 plan을 자동 생성하지 않는다. 허용 범위는 후보의 선택된 `story.scenes`와 해당 영역 extensions다.

- 연령에 맞는 어휘·문장 길이, 적절한 반복·리듬, 자연스러운 사건 전개를 사용한다.
- 감정 변화·선택·사건의 연결을 보여 주되 철학 개념을 길게 설명하는 교훈적 문장을 피한다.
- 승인된 캐릭터의 성격을 유지하고 열린 결말을 남긴다.
- 장면 수는 사용자 입력이 우선이다. 미정이면 12장면을 제안하고 확인하되 강제하지 않는다.
- `scenes: [{ id, text?, parentHint?, extensions? }]`에 작성한다. 개요의 sceneId를 재사용하고 순서 변경으로 ID를 바꾸지 않는다.
- 기존 이미지 참조가 있는 장면을 자동 삭제하지 않는다. 장면 추가·삭제·재정렬이 필요하면 구조 변경안을 먼저 제시한다.
- parentHint는 열린 질문과 관찰을 돕되 정답을 강요하지 않는다.

장면 간 연결과 인물 일관성을 검토하고, 수정으로 에세이·활동·그림이 어긋날 수 있으면 영향만 보고한다. 다른 콘텐츠는 재생성하지 않는다.
