# 편집 검수

검수는 원고를 자동 변경하는 모드가 아니다. 확인한 범위·자료·도구를 밝히고 실제로 확인하지 못한 항목은 미확인으로 표시한다. 결과는 `수정 필요 / 권장 / 미확인`으로 구분하며 위치·이유·제안을 함께 적는다. 별도 요청 시 후보의 `extensions.philoBookAuthor.editorialReview`에 보존할 수 있다.

| 기준 | 확인할 내용 |
| --- | --- |
| 철학적 정확성 | 개념 왜곡, 원전 취지와 해석의 혼동, 직접 인용과 위치의 정확성 |
| 학술적 신뢰성 | 자료 실재·저자/판본/DOI, 실제 확인 범위, 연구 대상·조건, 효과의 과잉 일반화 |
| 아동발달 적합성 | 연령별 어휘·인지 수준, 정서적 안전, 활동 난이도, 정답·감정 강요 여부 |
| 창작 완성도 | 독창성, 사건·장면 연결, 캐릭터, 리듬·가독성, 과도한 교훈·상투적 결론 |
| 콘텐츠 연계성 | 이야기-에세이의 철학적 일관성, 활동의 연결, sceneId와 이미지·화풍 일치 |
| 형식·보존 | 중복 제목·강조·목록·인용 서식, 고유 ID, 범위 밖 변경, 누락값·잘못된 참조 |

확인되지 않은 직접 인용·근거와 다르게 단정한 연구 효과·잘못된 장면 참조는 수정 필요로 분류한다. 문체·분량 등 선택 사항은 권장으로 구분한다. 자료 접근 불가나 사용자 판단이 필요한 것은 미확인으로 남긴다.

모든 항목에 실제 문제가 있다는 뜻으로 체크하지 않는다. 검수 통과와 스키마 통과는 다르며, 둘 다 사용자 승인이나 자동 출판을 뜻하지 않는다. 수정 요청을 받으면 revise 범위만 후보에서 바꾼다.

## 독립 검수와 전달 보고서

동화/에세이/놀이/이미지 가운데 요청한 영역만 검수할 수 있다. 검수와 원고 수정은 분리하고, 승인된 동화를 보존하며 에세이만 검토하는 흐름도 지원한다. 각 항목을 다음 열로 별도 `review-report.md`에 기록한다.

| 검토 대상·위치 | 관련 주장 | 문헌 ID·확인 범위/위치 | 자료 직접 확인 여부 | 검증 상태 | 문제점 | 수정 권장안 | 사용자 승인 상태·실제 근거 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 실제 scene/activity/step ID 또는 문단 | 철학자 직접 주장/후대 해석/교육적 응용/실증 결과 구분 | 미확인 문헌도 상태와 한계 기록 | 예/부분/아니오 | research-guide의 네 상태 | 없으면 ‘발견 못함’, 미검토면 ‘미검토’ | 후보로만 제시 | 미승인/부분 승인/승인/미확인, 범위와 실제 근거만 |

철학 원전·직접 인용, 문학 사실관계와 해석, 발달심리학/교육학 적용, 인지·정서적 연령 적합성, 과학적 묘사, 출처 없는 주장, 과잉 일반화, 해석과 실증 결과 혼동, 교육활동 안전·재현 가능성을 점검한다. 원전을 직접 확인하지 못한 인용문은 검증 필요로 남긴다. verified 문헌을 참조해도 개별 주장의 검증이 자동 완료되지는 않는다.

원문 이동·중복 통합은 출처 문단→목표 ID/필드의 대응표와 삭제 문구(없으면 없음)를 포함한다. 제목/번호 정리도 원문 사본에 보존한다. 분류·순서·번호·원문 보존·이미지 누락·미확인 서지·출판 전 쟁점을 별도 항목으로 기록한다. 보고서의 승인 문자열이나 AI의 검수 통과를 사용자의 실제 승인으로 간주하지 않는다.
