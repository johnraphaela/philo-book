# essay — 부모·교사용 문예지형 에세이

입력은 승인된 동화와 필요한 Research Brief 또는 제공 문헌이다. 독립 호출할 수 있고 사용자가 제공한 승인 동화도 사용할 수 있다. 허용 범위는 후보의 `essay`와 해당 essay.extensions다. research 기록 자체를 갱신하려면 별도 research/revise 요청이 필요하다.

기본 흐름은 동화의 철학 문제 → 철학자·개념 → 문학적/현대적 해석 → 발달·교육적 시사점 → 함께 생각할 질문 → 확인한 참고문헌이다. 모든 항목을 과도한 소제목·목록으로 쪼개지 말고 자연스러운 문단과 문장으로 엮는다. 깊이와 가독성의 균형을 유지하며 상투적 훈계로 끝내지 않는다.

- 원전의 취지와 창작적 해석을 구분한다. 기억에 의존한 직접 인용·정확한 페이지·가짜 서지정보는 쓰지 않는다.
- 연구 효과를 서술하면 해당 문헌과 주장 범위를 연결한다. 연구의 연령·조건·한계를 넘는 단정은 하지 않는다.
- 출처가 미확인이면 확정 참고문헌에 넣지 않고 essay.extensions의 검토 메모에 남긴다. 검증 상태는 research-guide.md를 따른다.
- `title`에 제목을 두고 `body`에는 같은 H1을 반복하지 않는다. `subtitle`, `tags`는 선택이다.
- body는 Markdown/MDX 호환 텍스트로 작성한다. 본문은 `##`부터 시작하며, 목록·인용문과 문단 사이를 구분한다. 코드블록으로 본문 전체를 감싸거나 강조 기호를 이스케이프하지 않는다.
- 확인한 직접 인용만 `>`로 표시한다. JSON 저장 시 개행·따옴표를 올바르게 직렬화한다. 실행 코드·import·외부 JSX를 원고에 추가하지 않는다.

후보 원본 검증과 Markdown 서식 점검은 정확한 철학·학술적 검증을 대신하지 않는다. 기존 사이트와 관련해 코드 수정이 필요하면 원고 범위를 넘기지 말고 별도로 보고한다.
