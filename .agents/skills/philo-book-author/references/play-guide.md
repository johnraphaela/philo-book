# play — 하버드 뇌놀이

입력은 사용자가 선택한 동화·철학 에세이와 연령·활동 맥락이다. 필요한 입력이 외부에서 제공됐다면 다른 단계를 실행하지 않는다. 제공되지 않은 에세이를 자동 생성하지 않는다. 일부 입력 없이 진행하라는 명시적 요청이 있으면 그 한계를 표시한다.

'하버드 뇌놀이'는 프로젝트의 콘텐츠 이름이다. 대학 공식 프로그램·인증·보증이나 특정 효과의 입증으로 표현하지 않는다. 연구 원리의 근거와 창작 놀이의 검증 여부를 구분한다.

후보의 `thinking.activities` 중 선택 활동에 작성한다. 관찰·이유 설명·관점 바꾸기·비교·상상·감정 표현·생활 속 적용을 조합할 수 있으며 활동/단계 수는 고정하지 않는다.

- 활동: `id`, 선택적 `title`, `description`, `steps`, `references`, `extensions`.
- 단계: `id`, 선택적 `title`, `goal`, `questions`, `explanation`, `extensions`.
- 아이가 할 활동, 후속 질문, 연령별 변형, 준비물·시간 등은 단계/활동의 extensions에 선택 저장한다. 예: `extensions.childAction`, `followUpQuestions`, `ageVariants`.
- 열린 질문과 충분한 기다림을 제안한다. 특정 답·감정 표현을 강제하지 않는다.
- 확인한 문헌만 references에 사용한다. 미확인 자료는 검토 메모에 남기고 검증 상태를 명시한다.
- 기존 ID와 다른 활동은 보존한다. 출판용 harvardPlay.desc로 직렬화하지 않는다.

연령·정서적 부담·활동의 실제 난이도·원고와의 철학적 연결을 검토한다. 뇌 발달 보장이나 과장된 신경과학 표현은 새로 작성하지 않는다.
