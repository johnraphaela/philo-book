# 검토 보고서 — 미승인 전달 예시

이 패키지는 Skill 검사 예시이며 실제 승인 원고·실제 연구 결과가 아니다. 파일 작성 예시만 제공하고 이미지 생성·첨부·압축·게시 완료를 주장하지 않는다.

| 검토 대상·위치 | 관련 주장 | 문헌·자료 확인 | 검증 상태 | 문제/한계 | 권장안 | 사용자 승인 |
| --- | --- | --- | --- | --- | --- | --- |
| essay.body | 기다림을 관찰로 읽기 | 원전·논문 사용 없음 | unverified | 교육적 해석이며 실증 효과 아님 | 논증·연령 적합성은 후속 검토 | 미승인 |
| daily-observation | 관찰·그리기 | 실험 검증 없음 | unverified | 안전·실행 난이도 미검토 | 보호자가 실제 맥락 확인 | 미승인 |

## 분류·순서·번호

가이드 → 대화 → 실천 배열 순서. 대화/실천은 별도 numberingGroup을 사용한다. 제목에 화면 번호가 없고 마무리는 대화의 extensions.closing에 있다. 실제 하버드 공식 프로그램·인증·효과를 주장하지 않는다.

## 원문 보존·중복·승인

신규 합성 예시로 외부 원문·기존 출판본·승인 이력이 없다. 원문 이동/삭제/통합 없음. 유사한 활동의 의미 검토, 원본 대조, 사용자 승인 진위 확인은 미완료다. 실제 원고에는 source 문단→대상 ID/필드 대응과 삭제 문구·실제 승인 범위를 기록해야 한다.

## 이미지와 출판 전 사항

river-observation 이미지는 pending, 실제 파일에 접근하지 않아 exists:null이다. 표지는 장면 이미지 재사용을 지정했지만 준비되지 않았다. images/ 폴더에 실제 이미지가 없고 출판 경로도 미정이다. 캐릭터/화풍 설정은 미제공. 표지/장면 그림 준비, 안전성·문헌·원고 검토와 사용자 승인이 필요하다. 현재 패키지 구조 검사 통과가 출판 준비 완료는 아니다.
